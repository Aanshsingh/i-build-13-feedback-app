# ⭐ Feedback App — I BUILD #13/80

An interactive Feedback App built using HTML, CSS, and JavaScript.

The application provides a simple interface for users to rate their experience and submit a written review.

## ✨ Features

- ⭐ Star rating interface
- 📝 Written feedback input
- 💬 Feedback submission
- 🎯 Dynamic messages
- ⚡ Popup notifications
- ✅ Form validation
- 📱 Responsive design
- 🎨 Modern dark UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## 🧠 What I Learned

- DOM manipulation
- Event listeners
- Click event handling
- Reading user input
- Conditional statements
- Form validation
- Dynamic UI updates
- JavaScript functions
- Responsive styling

## ⚙️ How It Works

1. Select a star rating.
2. Enter feedback in the text area.
3. Submit the feedback.
4. View the confirmation message.
